# Relax Valley

> 星露谷物语 1.6 的综合菜单模组 —— 把散落在山谷各处的信息、商店、传送与统计，收进一个现代化界面。

**Relax Valley** 基于 [SMAPI](https://smapi.io/) 与 [StardewUI](https://github.com/focustense/StardewUI) 构建，将日历、任务、商店、传送、村民社交、各类统计与进度等几十个功能整合进统一的菜单中，界面支持中英文，操作语义尽量与原版保持一致。

---

## 功能总览

主菜单按功能分为四个区块，另有独立的「工作室」页面（按 `B` 类功能聚合）：

### 信息与统计
| 功能 | 说明 |
| --- | --- |
| 日历 / 布告栏 | 原版界面直接打开 |
| 任务一览 | 汇总原版与模组任务（按来源 / 类型 / 状态筛选、支持搜索），**纯只读**，不会影响原版任务 |
| 特殊订单 / 核桃房订单 | 原版订单板；核桃房订单受「原版门禁」开关控制 |
| 农场电脑 | 支持背包内或已放置的农场电脑 |
| 杀怪统计 | 原版讨伐数据一览 |
| 赌场统计 | 原版赌场终端数据；默认需要锈钥匙（原版门禁） |
| 完美度追踪 | 原版齐先生的完美度界面；右键可调用完美手册（若安装） |
| 配方统计 | 原版制作菜单独立打开，页面顶部显示「已学 X / Y」进度 |
| 农场动物 | 全部农场动物概览：好感、饲养天数、今日状态 |
| 钓鱼情报 | 按**当前地点 / 季节 / 天气 / 时间**模拟原版垂钓判定，列出可钓鱼与占比（模组鱼自动包含） |
| 博物馆收藏 | 逐件列出可捐赠物品（矿物 / 古物 / 模组特殊捐赠品），按原版 context tag 自动分组，含悬浮框与 F1 支持 |
| 金核桃信息 | 收集进度与剩余数量 |
| 村民友谊 | 见下方「村民友谊」 |

### 地图与传送
- **当前地图**：用原版渲染管线绘制当前所在地图，支持拖拽平移、滚轮缩放（最高原生 4 倍），金色标记玩家位置
- 世界地图点击传送、农场 / 姜岛 / 模组区域地图等功能**正在重构完善中，暂未开放**（代码已就绪，会在悬浮提示与传送精确度完善后回归）

### 远程电梯
矿井与骷髅矿洞电梯，按存档最深层数解锁（可切换常开模式）。

### 村民友谊
- 全部村民卡片：好感度精确点数、每周送礼次数、今日状态
- **生日徽章**与「定位今日生日」（把生日村民置顶，不传送）
- 悬停预览：头像、行走图、当前位置与日程（含模组 NPC）、**送礼口味推荐**（个人口味与通用口味分列，模组修改自动生效）
- 可选功能（默认关闭，见配置）：**一键对话**、**批量送礼**（按原版送礼规则逐件赠送）、**传送**

### 工作室
- **基础设施**：缝纫机、染色罐、法师神龛、兑奖机、浮标机、统一花色、火山锻造台
- **建造与升级**：罗宾建造 / 升级、法师建筑、购买动物、砸晶石（复刻原版柜台交互）
- **远程商店**：原版商店全部支持远程购买，需先在游戏内打开过一次（可切换常开模式）；节日摊位当天自动列出
- **设施与存取**：购买背包、祝尼魔箱、出货箱、梳妆台、精通技能、杀怪奖励
- **模组商店**：自动发现所有往 `Data/Shops` 添加商店的模组，按模组分组置底，无需手动配置

### 其它
- **快捷键**：主菜单键可在 GMCM 修改；任意条目可绑定快捷键（支持组合键与一键多键，见下方配置）
- **主菜单置顶**：右键无右键功能的条目即可置顶，常用功能一目了然
- **Iconic Framework 兼容**：可在工具栏注册打开主菜单的图标
- **Lookup Anything 兼容**：博物馆与钓鱼情报的物品卡片支持 F1 查询（需 StardewUI fork 版）

## 安装

1. 安装 [SMAPI](https://smapi.io/)（4.0.0 以上）
2. 安装 [StardewUI](https://www.nexusmods.com/stardewvalley/mods/26280)（必需依赖）
3. （可选）[Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) —— 图形化配置界面
4. （可选）[Iconic Framework](https://www.nexusmods.com/stardewvalley/mods/11026) —— 工具栏图标
5. 解压 `RelaxValley` 文件夹到 `Mods` 目录

卸载时直接删除 `Mods/RelaxValley` 文件夹即可。

## 配置

### GMCM（推荐）
主菜单键、三个「进度 / 常开模式」开关、以及以下默认关闭的功能开关：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 商店进度模式 | 开 | 需先在游戏内打开过商店才能远程购买 |
| 村民友谊进度模式 | 开 | 未认识的村民不可互动 |
| 远程电梯进度模式 | 开 | 按最深层数解锁电梯 |
| 一键对话 | 关 | 友谊页显示「一键对话」按钮 |
| 友谊页传送 | 关 | 卡片互动菜单出现「传送」 |
| 批量送礼 | 关 | 友谊页显示「批量送礼」按钮 |
| 原版门禁 | 开 | 赌场统计需锈钥匙、核桃房订单需核桃房开启 |

### config.json（手动编辑）
- **`MenuShortcutKeys`**：条目快捷键，键为条目 Id，值为按键组合列表（支持组合键）。游戏内输入 `rv_list_entries` 可查看全部可用 Id：

  ```json
  "MenuShortcutKeys": {
    "Calendar": ["LeftControl + H"],
    "FarmAnimals": ["J"]
  }
  ```

- **`StatsMenuTypes`**：右键「农场动物」时尝试打开的外接菜单类型（高级用法，一般无需配置）。

## 兼容性

- 本模组**不硬编码任何数据**：配方总数、博物馆清单、商店列表、礼物口味、可钓鱼类等全部按当前加载的数据动态统计，Content Patcher / SpaceCore 等添加的内容自动计入
- 模组商店通过 `Data/Shops` 自动发现并按宿主模组分组
- 地图传送通过原版 Warp 数据反查，模组添加的世界地图区域自动获得传送支持
- 与常见大型模组（SVE、Ridgeside Village、Mt. Vapius 等）的开发环境经过实测；钓鱼判定直接模拟原版 `getFish`，使用正常机制添加的鱼全部兼容

## 已知限制

- Lookup Anything（F1）桥接需要 **StardewUI fork 版**（mushymato 维护的版本）；官方版下悬浮框信息仍可用，仅 F1 不可用
- 组合键快捷键无法在 GMCM 内编辑（引擎限制），需手动修改 `config.json`
- 金核桃无法按区域拆分进度（原版数据只记录总数，本模组不做虚假展示）
- 任务一览为**纯只读浏览**（有意为之）：接取任务请前往对应的 NPC 或布告栏
- 模组商店的中文显示名由自动翻译尽力生成，个别商店仍会显示英文 ID——可在 `assets/data/shop-names.json` 手动补充映射

## 模组开发者 API

其它模组可以把**自己的功能注册进 Relax Valley 的工作室菜单**（「模组支持」分类），让玩家在一个入口里看到所有模组功能：

```csharp
// 在你的 SMAPI mod 内（建议在 GameLoop.GameLaunched 事件中）：
var api = Helper.ModRegistry.GetApi<IRelaxValleyApi>("Awassakura.RelaxValley");
api?.RegisterMenuEntry(
    id: "YourMod.YourFeature",        // 唯一 Id，建议用你的 UniqueID 作前缀
    name: "你的功能名",                // 建议按当前游戏语言本地化
    onOpen: () =>
    {
        // 玩家点击条目时执行（此时 Relax Valley 菜单已自动关闭）
        Game1.activeClickableMenu = new YourMenu();
    });
```

- 接口类型 `IRelaxValleyApi` 定义在 Relax Valley 程序集中，安装了 Relax Valley 的玩家无需额外配置
- Id 冲突时注册返回 false；`UnregisterMenuEntry(id)` 可注销条目
- 未安装 Relax Valley 时 `GetApi` 返回 null，用 `api?.` 安全调用即可

### 构建
- 需要 .NET 6 SDK 与游戏环境（构建时通过 [ModBuildConfig](https://www.nuget.org/packages/Pathoschild.Stardew.ModBuildConfig) 自动定位游戏与依赖）
- 在项目根目录执行 `dotnet build`，产物自动输出至 `Mods/RelaxValley`

### 开发者控制台命令
`rv_list_shops`（列出全部商店 ID）、`rv_list_entries`（列出可绑定快捷键的条目）、`rv_f1diag`（诊断 F1 桥接状态）。这些命令会在正式发布前移除。
